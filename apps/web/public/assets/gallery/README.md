# Gallery images

Gallery entries and post cover images.

Everything here today is `gallery-placeholder-0N.svg` — abstract SVG
stand-ins, not photographs, awaiting owner-supplied field imagery.

Each image is described by a file in `content/gallery/`, which carries its
`status:` (`placeholder` / `illustrative` / `verified`). The gallery UI reads
that status and labels the image, so a placeholder can never be mistaken for
real fieldwork.

To replace one: drop the real file here, update the `image:` path and set
`status: verified` in the matching content file.
